# Security Policy

## Supported versions

Security fixes are released for the latest version of `pysqlx`.

## Reporting a vulnerability

Please do not report a vulnerability in a public issue.

Report it privately on GitHub: open the [Security tab](https://github.com/pysqlx/pysqlx/security) of the repository and choose "Report a vulnerability". Describe what is affected, how to reproduce it, and what an attacker could do with it.

You can expect a first answer within a week. When the report is confirmed, a fix is prepared in private, released as a new version, and then described in a security advisory which credits you, unless you prefer otherwise.

## What the package protects against

The [security page of the documentation](https://pysqlx.readthedocs.io/en/latest/guide/security.html) describes what `pysqlx` does to keep queries safe, and what remains the responsibility of the code which uses it.
